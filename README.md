# Pulse

[Play now!](https://htmlpreview.github.io/?https://github.com/AidenKranz/Pulse/blob/main/Pulse.html)

## Core mechanic: 
 
The goal of each puzzle is to redirect moving pulses of light onto a target. The core mechanic will be using mirrors to reflect pulses towards the target and around obstacles. In order to win, a target must detect several consecutive pulses in a row (the player should find a stable solution). 
 
## Ancillary mechanics: 
 
-	Moveable mirrors - some mirrors can be moved by the player 
-	Toggleable mirrors - some mirrors can be toggled/rotated 
- Pulse redirection - when 2 pulses collide at a 90 degree angle, they combine and begin to move diagonally (N+E=NE). 
-	Color combination - when 2 pulses collide with different primary colors, they combine to create the corresponding secondary color 
-	Crates - these will block the path of pulses for better or worse 
-	Splitter mirrors - These mirrors toggle every time they reflect a pulse
